# To-Do List Web App

A simple and secure To-Do List application built using **HTML, CSS, JavaScript, Node.js, Express, and MySQL**. Users can sign up, log in, and manage their personal task list in a clean interface.

## Features

- User authentication with login and signup.
- Passwords hashed using bcrypt for security.
- Create, delete, and mark tasks as completed.
- Tasks linked to individual users via user ID (foreign key).
- Sessions managed securely with `express-session` and a MySQL session store.
- Clean UI built with vanilla HTML, CSS, and JS.


## What I Learned

Through this project, I gained hands-on experience with:

- **Frontend & Backend Integration** – Sending and receiving data using `fetch()` and handling JSON responses.
- **User Authentication** – Implementing login/signup flows with secure password storage using bcrypt.
- **Session Management** – Maintaining user state using sessions and protecting routes.
- **Node.js & Express** – Creating a RESTful API for authentication and task CRUD operations.
- **MySQL Database Design** – Structuring tables with relationships (foreign keys) and writing secure queries.
